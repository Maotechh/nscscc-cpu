# Generated Component Replacements

Leaf replacements in this directory are generated by the locked Scala/SBT/SpinalHDL toolchain so differential overlays can consume ordinary Git blobs instead of local build directories.

The active whole-CPU package is generated by `openla500.compat.GenerateCoreTopCompat` and committed as `rtl/mycpu_top.v`, which is the canonical FPGA-client overlay path. `core-top.json` binds that generated blob to the locked `a158aa8` target and its SHA256. Leaf files here remain differential evidence and must not be overlaid together with the self-contained top.
